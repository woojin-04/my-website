# AI 기반 경영컨설팅 서비스 웹사이트

## 프로젝트 개요

지도교수님과 함께 에이전틱 AI와 온톨로지를 기반으로 한 경영컨설팅 사업 아이디어를 구체화하는 과정에서 제작한 웹사이트입니다.

실제 사업화까지 이어지지는 않았지만, 아이디어를 실제 웹서비스 형태로 구현하는 것을 목표로 약 2주간 제작했습니다.

## 주요 작업

- Claude를 활용한 웹사이트 제작
- 요구사항 작성 및 반복적인 수정·보완
- Supabase 연동 : 사용자 게시글 작성 및 조회가 가능한 커뮤니티 기능 구현
- GitHub를 통한 코드 관리 및 배포

## 사용 도구

- Claude
- HTML / CSS / JavaScript
- Supabase
- GitHub
